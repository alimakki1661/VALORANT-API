About the APIs

The Content API gives you game metadata from riot, agent names, map IDs, current version, that kind of stuff. The Platform Status API tells you if there are any active outages or maintenance windows for a specific region. I used NA for this project.

What I Built

  • Loading and displaying real API response data
  • Search and filter for agents and maps
  • Alphabetical sort (A-Z and Z-A)
  • Per map agent stats with pick rate, ACS, ADR, and K/D
  • Responsive layout using Bootstrap

This uses Riot's VALORANT Content and Platform Status APIs. The public version runs off saved response data so I'm not exposing my API key.
