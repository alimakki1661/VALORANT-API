About the APIs

The Content API pulls game metadata from Riot — things like agent names, maps, and the current version. The Platform Status API tells you if there are any active incidents or scheduled maintenance for a given region (in this case, NA).

What I Worked On

  • Fetching and parsing real API responses
  • Rendering JSON data dynamically on the page
  • Search/filter and sort functionality in vanilla JS
  • Responsive layout using Bootstrap
  • Keeping API keys out of the public repo
