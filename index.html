About the APIs

The Content API is used to retrieve official VALORANT metadata such as agents, maps, acts, and version information. The Platform Status API is used to retrieve service health information, including incidents and scheduled maintenance.

What This Project Demonstrates

  • Working with official API response data
  • Displaying JSON on a website
  • Filtering and sorting at code level
  • Creating a responsive dashboard with Bootstrap
  • Building a presentation-ready class project website

Built as a course project using Riot VALORANT Content and Platform Status endpoints. Public website version uses saved response data instead of exposing a live API key.
